## Objective
- Build a signed Android APK (and AAB for Google Play) from the PWA at `https://lens.amirhossein-service.ir/login`, with splash screen, app icons, and release signing for store submission.

## Important Details
- The website is behind **ArvanCloud CDN** which aggressively caches `index.html` and APIs, causing the APK to load stale code even after deployment.
- **SSL certificate mismatch**: issued for `amirhossein-service.ir`, not the subdomain `lens.amirhossein-service.ir`. Samsung WebView may silently fail unless handled.
- `unpkg.com` (Leaflet CDN) is **unreliable/blocked in Iran**, causing `ERR_QUIC_PROTOCOL_ERROR` and broken maps.
- `.env` contains the real production admin password: `ADMIN_PASSWORD=264766@Zz264766@Zz` (committed and pushed).
- `UPLOAD_DIR` was fixed from `./uploads` (empty) to `./server/uploads` (has images) after Docker volume mismatch caused 404s.
- The working APK is built from a **completely fresh** Capacitor 6 Android project with `@capacitor/splash-screen` **removed**; splash is handled natively via `styles.xml` + `splash_screen.xml`.
- `Thread.sleep(3000)` in `MainActivity` was attempted and **reverted** because it blocks the UI thread and crashes the WebView.
- Node v20, OpenJDK 21, Android SDK 34, Gradle 8.2.1.
